# S-Py-re

A bare-bones deckbuilder roguelike inspired by Slay the Spire, built with Python and Pygame.

## Purpose

Learning project to practice game development and implement card game mechanics.

## Requirements

- Python 3.12+
- Pygame

## Installation
```bash
pip install pygame
```

## Usage
```bash
python main.py
```

## What's Implemented

* Functional battles: the player will play cards under a certain energy cost until they defeat an enemy. Enemies will fight back following an array of intents (attacking, buffing themselves, etcetera).
